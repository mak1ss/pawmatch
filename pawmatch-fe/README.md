# PawMatch frontend

Web client for PawMatch, the dog breed recommendation service. React 19, TypeScript, Vite, React Router,
TanStack Query, Tailwind CSS with shadcn/ui, MSW and Vitest.

```
npm install
npm run dev     # http://localhost:5173
npm test
```

The backend is in [`../pawmatch`](../pawmatch). See [`CLAUDE.md`](CLAUDE.md) for the product scope, API contract,
conventions and how to run the backend locally.
